## Why

HTML-документы уже прикрепляются к задачам Multica, но из plugin surface их нельзя обнаружить и открыть как компактный список. Пользователю приходится искать вложение среди комментариев, хотя штатный preview уже умеет безопасно показывать этот файл.

## What Changes

- Добавляется минимальный read-only контракт Plugin API для перечисления вложений текущей задачи: только идентификатор, имя файла и MIME type.
- Добавляется host-команда Plugin SDK, открывающая выбранное вложение в существующем штатном preview после проверки принадлежности текущей задаче.
- Добавляется изолированный plugin `html-attachment-links`, который показывает в правой колонке только HTML-вложения как ссылки.
- Для каждой ссылки разрешается задать короткий заголовок; при отсутствии заголовка показывается имя файла. Заголовки хранятся в workspace storage как минимальное соответствие `attachment_id -> title` в пределах задачи.
- Не добавляются SHA, даты, категории, фильтры, внешний реестр, публикация копий, сканирование сторонних URL или универсальная платформа метаданных.

## Capabilities

### New Capabilities

- `plugin-attachment-access`: минимальное чтение вложений текущей задачи и безопасное открытие существующего вложения через штатный preview.
- `html-attachment-links`: список ссылок на HTML-вложения и редактирование коротких отображаемых заголовков в issue panel.

### Modified Capabilities

Нет.

## Impact

- Новый plugin остаётся внутри `plugins/html-attachment-links/` и использует только `issues:read` и `storage:workspace`.
- Минимальный platform gap затрагивает Public/Plugin API, surface bridge и Plugin SDK Multica; модель вложений и штатный preview не меняются.
- Новых сторонних зависимостей, сетевых разрешений, миграции данных и публичных внутренних URL нет.
