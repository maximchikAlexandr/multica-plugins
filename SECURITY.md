# Security Policy

## Reporting a vulnerability

Do not open a public GitHub issue for a suspected vulnerability. Email `maximchik.alexandr@yandex.ru` with:

- a description of the vulnerability;
- reproduction steps, when available;
- the potential impact;
- a suggested fix, if known.

Do not include secrets, credentials, private webhook URLs, or internal report links in commits, pull requests, or issues.

## Supported versions

Until the first release, only the current `main` branch is supported.
